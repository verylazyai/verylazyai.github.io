# VeryLazyAI - Free AI Tools Directory

## 🚀 Features

- **Clean & Minimal Design** - Modern, futuristic UI with subtle AI vibes
- **Smart Search** - Instant search across all tools
- **Category Filtering** - Easy navigation by tool type
- **Tool Details Modal** - Click any tool for detailed information
- **Video Embeds** - Promotional videos for major tools
- **Fully Responsive** - Works perfectly on all devices
- **No Backend** - Pure static site for easy deployment
- **Fast & Lightweight** - Optimized for speed

## 📋 Categories

- ✍️ Writing (ChatGPT, Claude, Gemini, QuillBot)
- 🎨 Images (DALL-E, Midjourney, Stable Diffusion, Leonardo AI)
- 🎬 Video (Runway, Pika, HeyGen)
- 💻 Code (GitHub Copilot, Cursor, Replit, Codeium)
- 🎵 Audio (ElevenLabs, Murf AI, Suno)
- ⚡ Productivity (Notion AI, Otter.ai, Grammarly, Zapier)
- 🔍 Research (Perplexity AI, Consensus, Elicit, Wolfram Alpha)


## 📊 Performance

- **Lighthouse Score**: 95+ on all metrics
- **Load Time**: < 1 second
